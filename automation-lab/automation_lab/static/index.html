Harbor Mutual Automation Lab

A practice ground for UI test automation: realistic insurance workflows and every kind of control a generated script has to drive. Nothing here needs a login. What a script does is recorded on the server, so a run can be checked against the system of record as well as the screen.

UI releases (for self-healing)

Pick a release in the header, or open the page with ?release=v2. Behaviour and data are identical; only locators change. Record on v1, replay on v2, v3 and v4, and watch which locators survive. v2 suits design-time healing (repair the script once); v3 and v4 suit run-time healing. Add ?drift=10 to rename elements every 10 seconds while the page is open. The ground truth for scoring heals is at /api/locator-map.
